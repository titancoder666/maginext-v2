# 二维码资源

- `wechat.png` — 主微信号 `maginex-edu` 的永久二维码（240×240 或更大）
- `whatsapp.png` —（可选）WhatsApp QR

## 生成方法

**微信永久二维码**（推荐方式）：
1. 用企业微信注册，进入"通讯录"→ "我的二维码"→ 选"邀请客户"
2. 下载得到的图片（永久不过期）
3. 替换本目录下的 `wechat.png`

**或个人微信码**（会过期，每月需更新）：
1. 微信"我"→ "我的二维码"
2. 截屏后裁剪
3. 上传

如果文件不存在，前端会自动 fallback 到文字 + 复制按钮。
